# OS MIDI Editor

The Old School MIDI Editor for Mac: a free MIDI file editor inspired by the Cubase and
Cakewalk of the '90s, with Arrange, Piano Roll, Drum Editor, Event List, a built-in SoundFont
synthesizer and automatic karaoke chords from any tab.

This repository only hosts the downloads.
